# Change notes

## main (unreleased)

- among-us (experimental): up to fifteen ego-driven agents (a full lobby, 1–3 impostors by the game's lobby limits) play a deterministic Among Us simulation through the new `among_us_agent_turn` workflow (perceive, remember, believe, decide, validate), one Hive Mind session per agent, with ego-dependent encoding and forgetting, evidence-checked actions, replays and leakage/recall/validity metrics. (working/among-us-slice)
- among-us: spectator dashboard at `/among-us` — start a match, live ship map from a spectator-only ground-truth endpoint, decision feed, agent cards with memory timeline and suspicions, evaluation view; plus `GET /among-us/api/matches` and `/map`. (working/among-us-slice)
- among-us: structured location claims on meeting statements, validated (known player, past tick, evidence for claims about others) and scored against true positions: lies, detectable lies, self-contradictions, deception consistency, crew mistakes by memory mode. (working/among-us-slice)
- among-us: add the chat-history baseline workflow (`among_us_agent_turn_baseline`: verbatim, never-forgetting, bounded transcript, no beliefs), mixed ego/baseline lobbies, context size per model turn, and an evaluation by memory mode. (working/among-us-slice)
- among-us: a declined kill opportunity is a decision point again only when the potential victims change. (working/among-us-slice)
- among-us: schedule agent turns — priority (meetings, salient observations first), a cap on concurrent model turns, a per-tick model budget with policy fallback, and a per-turn deadline; every decision records its scheduling mode. (working/among-us-slice)
- among-us: define ego files by one strict pydantic schema (typed, ranged, sectioned by cognitive stage, no unknown keys) with a generated JSON schema for editors. (working/among-us-slice)
- among-us: define bridge protocol v1 (NDJSON over loopback) with shared fixtures and a `BridgeEnvironment` client. (working/among-us-slice)
- among-us: the real game runs through the nlght Impostor server (nlght-ai-impostor) instead of a client mod: observations carry the lobby `roster` so humans are suspects too, agents get their ego by bot name, a bridge match needs no player map, and a decision request produced by the server is a contract fixture. The unbuilt BepInEx/Reactor client-mod skeleton is removed. (working/among-us-slice)
- trigger: split `build_invocation()` out of `build_http_invocation()` so in-process callers can start workflows without an HTTP request. (working/among-us-slice)
