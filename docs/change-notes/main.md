# Change notes

## main (unreleased)

- among-us: meetings become a conversation. Observations in meetings carry `meeting_chat` (the chat so far, verbatim); the decide step adds meeting rules (answer, weigh, ask, agree or push back, no repetition, WAIT when nothing is new) and shows the agent its own lines; the policy fallback defends, accuses, takes sides and asks instead of one fixed line. A decision reason `reassess:` (e.g. a kill called off) is scheduled like a salient observation. (topic/among-us)
- among-us: one model per agent. Ego files may name a `[model]` (provider, model); the admin view chooses per agent and lobby (`PUT /among-us/api/lobbies/{id}/agents/{agent}/model`), else the platform default applies. `GET /among-us/api/models` lists every provider's models through its nlght backend (`list_models()`). Each turn carries `model_provider` and `model`; `seed/08_among_us.sql` no longer pins a provider in the decide steps — load it again, an older seed is refused with a hint. (topic/among-us)
- among-us: admin view of the registered lobbies in the dashboard: agents with role, alive/dead, room, last action, latency, decisions, initiatives and model choice; suspects and recalled memories per agent. (topic/among-us)
- among-us: agents act on their own initiative between decisions. After each observation (which now carries the legal actions of the task phase) a crewmate whose suspicion of a living player reaches the new ego parameter `judgement.call_meeting_at` calls an emergency meeting, citing its evidence, once per piece of evidence; the lobby records each initiative with the game's verdict and counts them per agent. (topic/among-us)
- among-us: replace the bridge match with lobby sessions (protocol v2). The nlght Impostor server registers a lobby when its host types `!bots`; the orchestrator picks free egos and names the agents, so the server spawns exactly those. Every lobby has its own token and session (`/among-us/api/lobbies/{id}/messages` in, `/stream` out), lives across its games and opens a new match per game. Observations write memory without a decision, decision requests carry an id and the game's deadline (the scheduler honours it, a newer request cancels an older one), the orchestrator may send actions on an agent's own initiative, and `game_ended` reports every player's role. `BridgeEnvironment`, name-based ego assignment and `{"environment": "bridge"}` are removed. (topic/among-us)
- among-us: the fallback policy no longer fails on task names the simulated ship does not know. (topic/among-us)
- among-us (experimental): up to fifteen ego-driven agents (a full lobby, 1–3 impostors by the game's lobby limits) play a deterministic Among Us simulation through the new `among_us_agent_turn` workflow (perceive, remember, believe, decide, validate), one Hive Mind session per agent, with ego-dependent encoding and forgetting, evidence-checked actions, replays and leakage/recall/validity metrics. (working/among-us-slice)
- among-us: spectator dashboard at `/among-us` — start a match, live ship map from a spectator-only ground-truth endpoint, decision feed, agent cards with memory timeline and suspicions, evaluation view; plus `GET /among-us/api/matches` and `/map`. (working/among-us-slice)
- among-us: structured location claims on meeting statements, validated (known player, past tick, evidence for claims about others) and scored against true positions: lies, detectable lies, self-contradictions, deception consistency, crew mistakes by memory mode. (working/among-us-slice)
- among-us: add the chat-history baseline workflow (`among_us_agent_turn_baseline`: verbatim, never-forgetting, bounded transcript, no beliefs), mixed ego/baseline lobbies, context size per model turn, and an evaluation by memory mode. (working/among-us-slice)
- among-us: a declined kill opportunity is a decision point again only when the potential victims change. (working/among-us-slice)
- among-us: schedule agent turns — priority (meetings, salient observations first), a cap on concurrent model turns, a per-tick model budget with policy fallback, and a per-turn deadline; every decision records its scheduling mode. (working/among-us-slice)
- among-us: define ego files by one strict pydantic schema (typed, ranged, sectioned by cognitive stage, no unknown keys) with a generated JSON schema for editors. (working/among-us-slice)
- among-us: define bridge protocol v1 (NDJSON over loopback) with shared fixtures and a `BridgeEnvironment` client. (working/among-us-slice)
- among-us: lights and comms sabotage (crew sees only "someone" in the dark; crew cannot see its tasks), closing doors, and the special impostor roles Shapeshifter (perceived as the copied player) and Phantom (not perceived while invisible); perception follows appearance, observations carry `outages` and the own `special_role`, `disguised_as` and `vanished`, the evaluation counts misattributed kill sightings. (working/among-us-slice)
- among-us: impostor play — `VENT` and `SABOTAGE` actions, `KILL_COMMITTED` own-kill memories (only the killer perceives them), `VENT_SEEN`, `SABOTAGE_ALARM`/`SABOTAGE_FIXED` and the public `alarm` in observations, a decision point after each kill, self-reporting, and `impostor_play` in the evaluation; the dashboard marks an active sabotage. (working/among-us-slice)
- among-us: fix a leak in the simulation — meeting observations showed where every other player was; at the table they are now only "meeting", as in the real game. (working/among-us-slice)
- among-us: a bot named like an ego keeps that ego; free egos go to the other bots only afterwards. (working/among-us-slice)
