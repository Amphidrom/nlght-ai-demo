# Offline mode

Northstar Desk keeps every draft in a local store while the workspace is offline.
A draft written offline is synchronized automatically once connectivity returns.

## Conflicts

When the same document was edited on two devices while offline, Northstar Desk keeps
both versions and marks the document as conflicted. A conflicted document must be
resolved by a person before it can be shared again.

## Limits

Offline mode holds at most 500 drafts per workspace. A workspace that reaches the
limit stops accepting new offline drafts until it has synchronized.
